# The SITE Loop Architecture

The SITE loop is a continuous 4-phase lifecycle for SEO and Generative Engine Optimization (GEO).

```
   ┌────────────────────────────────────────────────────────┐
   │                                                        │
   │   ┌──────────┐     ┌───────────┐     ┌──────────┐      │
   └──►│  Survey  ├───► │ Implement ├───► │   Tune   ├──────┘
       └──────────┘     └───────────┘     └────┬─────┘
                                               │
                                               ▼
                                          ┌──────────┐
                                          │ Evaluate │
                                          └──────────┘
```

## 1. Survey: Understanding the Search Landscape
Before creating content or writing code, understand what users search for, what AI engines synthesize, and how competitors rank:
- Identify target keywords, search intent (BOFU, MOFU, TOFU), and search volume.
- Mine striking-distance queries (positions 5–20) that can quickly rank on page one.
- Analyze competitors' content footprints, backlink velocity, and AI citation visibility.
- Audit SERP features (featured snippets, People Also Ask boxes, video packs).

## 2. Implement: Creating High-Performance Search & AI Assets
Transform search insights into optimized, quotable content:
- Write comprehensive, user-centric articles with direct answer structures.
- Apply Generative Engine Optimization (GEO): entity definitions, concise summaries, comparison tables, and factual data citations.
- Generate valid Schema.org structured data (JSON-LD) for rich snippet eligibility.
- Deploy specialized page play templates (programmatic pages, comparison hubs, local landing pages).

## 3. Tune: Elevating Quality & Technical Hygiene
Ensure perfection across user experience, crawlability, and search standards:
- Run the 80-item CORE-EEAT audit to catch factual inaccuracies, low originality, or structural flaws.
- Verify technical foundation: Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1), sitemaps, robots.txt directives, canonical URLs, and mobile responsiveness.
- Ensure LLM crawler access (permit GPTBot, ClaudeBot, PerplexityBot in robots.txt unless private data).
- Optimize internal link architecture (hub-and-spoke topic silos).

## 4. Evaluate: Measuring Authority & Defending Search Moats
Track performance trends, authority metrics, and AI referral attribution:
- Run the 40-item CITE domain trust evaluation.
- Monitor keyword rank distributions and diagnose position drops.
- Set threshold alerts for organic traffic drops, indexing regressions, or crawl anomalies.
- Analyze backlink quality, eliminate toxic link patterns, and track AI assistant referrals.
